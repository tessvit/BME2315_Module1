# BME2315_Module1
Tess Vithoulkas and Theresa Illicete
Professor Pierce-Cottler

Analyzing Alzheimer's Metadata and Protein Data

Analyzed patient data with graphs and statistical analyses to observe relationships between sex and AB-42 concentration, education level and AB-42 concentration, and AB-42 concentration and age at death. Results aligned with existing literature, suggesting no statistical difference between any of the groups.
